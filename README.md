# 💰 Spentrace – Personal Budgeting App  

Spentrace is a responsive budgeting app that helps users **track income, expenses, and bills** while providing insights into available spending and upcoming financial needs. The app simplifies money management by consolidating earnings, bills, loans, and credit card balances into one clean dashboard.  

---

## 🚀 Live Demo  
- [Frontend](https://www.spentrace.com)  
- [Backend API](https://spentrace-backend.herokuapp.com/)  
- [Backend Code](https://github.com/Bernard-Calma/spentrace_backend)  

---

## ✨ Features  

- 👤 **User Accounts** – Sign up, sign in/out, and manage personal financial data securely  
- 💸 **Budget Tracking** – Add, edit, and delete income/expense entries  
- 🧾 **Bills Management** – Record bills, mark payments, and track due dates  
- 🏦 **Bank & Credit Accounts** – Manage bank balances, credit cards, and loans  
- 📊 **Expense vs. Income Dashboard** – Visualize spending habits vs. earnings  

---

## 🛠️ Tech Stack  

- **Frontend:** React, Redux, JSX, JavaScript, CSS, HTML  
- **Backend:** Node.js, Express, MongoDB (Mongoose ORM)  
- **Styling:** CSS, Font Awesome  
- **Deployment:** Heroku
